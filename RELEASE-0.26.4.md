# Local Route 0.26.4 — Windows beta

Единое приложение для локального DPI-обхода YouTube/Discord, VPN через собственный VLESS/Hysteria2-сервер и локального Telegram WebSocket-прокси.

## Что нового

- EXE-установщик с выбором каталога, ярлыками и удалением.
- Более быстрый прогрев окна из трея, подготовка сети и независимый запуск VPN/Telegram после DPI.
- Подписки и выбор серверов; VPN с исключениями сайтов и приложений.
- Ручной замер скорости через VPN: до 10 МБ и 20 секунд, без перезапуска туннеля.
- Проверка пути автозапуска и попытка переноса на текущую установленную версию.
- Постоянные предупреждения при аварийном отключении VPN и сброс прежней проверки после сна.
- Ошибка расшифровки старого хранилища больше не ломает интерфейс; исходные данные сохраняются.
- Выровнены настройки запуска; название в интерфейсе — Local Route без Community.

## Установка

Скачайте `Local-Route-Setup-0.26.4-x64.exe` из Assets. При первом запуске нужны права администратора для сетевых компонентов. Для обновления полностью завершите прежнюю копию через трей.

VPN-серверы и подписки не предоставляются: добавьте свои. Если сохранённые данные не расшифровываются, используйте исходную ссылку/подписку; не публикуйте её в Issues.

## Проверено и ограничения

139 автоматических тестов, проверки интерфейса, установка/удаление предыдущего кандидата 0.26.3 с сохранением настроек и реальный HTTPS-запрос через VPN. Для 0.26.4 повторно проверены интерфейс и сборка установщика.

Это бета: поведение после сна, смены сети и перезагрузки ещё требует проверки на разных ПК. EXE без подписи издателя. Kill switch отсутствует: при падении VPN трафик может пойти напрямую. DPI и исключения намеренно используют прямое подключение. Тест скорости до Cloudflare не отражает скорость всех сайтов. Работа обхода зависит от сети.
