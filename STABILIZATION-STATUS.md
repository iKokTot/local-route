# Исполнение аудита, этапы 1–2: 0.28.0

Это статус работ, а не объявление закрытия всего аудита.

| Пункт | Состояние | Доказательство / остаток |
|---|---|---|
| A01 runtime | Сделано | Electron 44.9.3, точный pin; реальный isolated smoke |
| A02 привилегии | Не сделано | UI/main остаются elevated; отдельный защищённый helper и миграция установки необходимы |
| A03 health | Частично | Отдельный HTTPS monitor, backoff, срок актуальности; не полная сертификация маршрутов |
| A04 сетевой E2E | Не сделано | Реальный TUN/IPv6/DoH/sleep/provider matrix пока не пройден |
| A05 падения | Частично | Job Object/supervisor для собственных ядер; реальные fixture crash-тесты и isolated Electron exit пройдены. Восстановление реальных драйверов/маршрутов после аварии ещё не сертифицировано |
| A06 скорость | Сделано | HTTP 200 + полный объём; тесты статусов и усечённых файлов |
| A07 DPI | Частично | Endpoint-specific HTTP ожидания и честные подписи; ручное подтверждение видео/голоса Windows ещё не реализовано |
| A08 очереди | Частично | Stop VPN отменяет собственный запуск; общая очередь других операций остаётся |
| A09 DNS | Частично | Общая non-recursive policy; нужны fallback, UI диагностики исключений и дополнительные реальные сценарии |
| A10 отказ/IPv6 | Не сделано | Поведение fail-open не менялось; kill switch не обещается |
| A11 производительность | Частично | Кэш безопасной публичной проекции исключает повторную расшифровку неизменившейся библиотеки. Sync store и большие end-to-end профили ещё предстоят |
| A12 сборка | Частично | Clean staging, engine manifest, scripts, Linux workflow; remote CI/Windows release pipeline/подпись не проверены |
| A13 дублирование | Сделано для downloader/DNS | Один download transport и общий DNS policy; main.js ещё требует декомпозиции |
| A14 секрет TG | Не сделано | По-прежнему аргумент процесса; нужен изменённый wrapper/core transport |

Локально: полный прогон предыдущего этапа — 151 тест; текущий прогон дополнен тестами supervisor, кэша и resume. Electron smoke дополнен проверкой завершения принадлежащего ему fixture. Сетевые ядерные бинарники не обновлялись; engine-lock фиксирует текущий локальный набор, не новую проверку происхождения. Точное число итоговых тестов указано в RELEASE-0.28.0.md.

Следующий самостоятельный этап: защищённая установка и privilege boundary, затем аварийные и сетевые E2E с настоящим TUN/WinDivert в Windows. Не менять схему автозапуска/ACL/службы на рабочей машине без миграционного плана и отката. Установленное приложение не заменялось; публикация не выполнялась.
