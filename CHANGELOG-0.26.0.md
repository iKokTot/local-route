# Local Route 0.26.0 — управление, скорость, исправления аудита

## Интерфейс

- Одна колонка на DPI / Telegram / VPN. Основные действия сразу под заголовком, настройки ниже; пустые соседние колонки убраны.
- Единый порядок трёх команд: запуск → проверка или открытие Telegram → остановка. Остановка выделена отдельно, не окрашивается как успешный запуск и не вызывает toggle, способный случайно включить выключенный VPN.
- Серверы, импорт, автовыбор и удаление перенесены в сворачиваемый раздел. На основном экране остаются выбранный сервер и состояние проверки.
- Порт Telegram, ручная ссылка, помощь и ручные DPI-стратегии раскрываются при необходимости.
- Уменьшены отступы свёрнутых блоков; результат проверки сервера раскрывается после запроса пользователя.
- Отдельно показаны «туннель готов», «сервер ещё не проверен», результат и время ручной проверки. Это не обещание полной работоспособности всех сайтов.

## Скорость

- Проверка готовности VPN использует фактически открытый локальный порт того же ядра вместо обязательного ожидания 1300 мс.
- Работающий VPN проверяется через собственный loopback HTTP-inbound. Дополнительный sing-box для этой проверки не запускается. Диагностический inbound принудительно направлен в VPN раньше прямых правил приложения.
- Повторное обнаружение сети кэшируется на 5 секунд с инвалидацией при изменении адресов/интерфейсов. Ошибки и отменённые результаты не кэшируются. Первый опрос PowerShell по-прежнему может занимать несколько секунд.
- Для одиночного процесса sing-box используется прямое завершение с ожиданием подтверждения; остановка деревьев TGWs и других компонентов не менялась.
- При подборе DPI сохраняется один набор прямых правил VPN. Туннель не перезапускается для каждого кандидата с теми же доменами. После завершения или отмены набор приводится к фактическому состоянию DPI.
- Фоновая подготовка окна после автозапуска больше не ждёт окончания всей процедуры сетевого запуска.

Во время краткого замера простоя у процессов интерфейса CPU был около нуля; замер слишком короткий для вывода о нагрузке под трафиком.

## Исправления

- Обновление подписки согласует выбранный сервер с новым списком. Однозначное соответствие обновляет параметры; удалённый/неоднозначный сервер требует повторного выбора. Неподдерживаемая ядром замена не портит прежний профиль.
- JSON-импорт сохраняет ALPN, enabled-флаги TLS/uTLS/Reality; неподдерживаемый тип обфускации не подменяется другим. Локальные пути и чужие входящие/маршрутные правила не импортируются.
- Пароли Hysteria2 и obfs передаются редактору журналов; ссылки hy2/hysteria2 также скрываются, включая строки, разбитые на фрагменты.
- Загрузка и текстовый импорт ограничены 2 МБ. До трёх HTTPS-перенаправлений разрешены только в пределах исходного origin, с общим таймаутом. Для другого сервера требуется конечная ссылка вручную.
- Счётчик в свёрнутом заголовке исключений обновляется при ручном добавлении домена.

## Проверка и ограничения

129 автоматических тестов: регрессии аудита, IPC, маршруты, отмена операций, настройки, интерфейс и конфигурации комплектного ядра. Проверки синтаксиса всех JS-файлов проходят.
Проверена конфигурация диагностического inbound для VLESS и Hysteria2 комплектным sing-box.
Не заявляются измеренный рост интернет-пропускной способности, отсутствие DNS/IPv6-утечек в каждой сети или автоматическое восстановление после сна. Это отдельные интеграционные проверки.
Публикация не выполнялась. Перед обновлением полностью завершите старую версию через трей, затем распакуйте новый ZIP в отдельную папку.
