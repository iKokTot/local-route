# Local Route 0.26.6 — локальный кандидат

- Исключённые домены получают собственную DNS-привязку FakeIP вместо зависимости только от общего IP CDN и распознавания SNI.
- Финальное разрешение прямых соединений явно направлено в локальный DNS; DNS исключённых приложений также направляется напрямую.
- Привязки исключений сохраняются локально между перезапусками VPN; DNS-кэш Windows обновляется при запуске/остановке. TTL синтетических ответов ограничен 60 секундами.
- Исправлены отступы между кнопкой замера скорости и результатом.

Проверка: изолированный комплектный sing-box с локальными DNS/HTTP-серверами восстанавливает исключённый домен из IP и выбирает прямой маршрут. Проверка не использует настоящий TUN или VPN-сервер.

Ограничения: браузер с собственным DoH может обходить DNS приложения; ранее открытые соединения и кэш браузера требуют полного закрытия браузера. Восстановление доступа к Авито на реальной машине требует отдельной проверки после установки. Антибот-ограничения сайта не снимаются приложением.

Эта сборка не публиковалась и не устанавливалась автоматически.
