# Local Route 0.29.0 — Windows beta

DPI для YouTube и Discord, VPN через ваш VLESS/Hysteria2-сервер и локальный Telegram-прокси в одном приложении.

## Что изменилось с 0.26.5

- Исправлена политика DNS: прямое разрешение исключений больше не использует системный DNS, который может попасть обратно в собственный TUN. Для исключённых доменов сохраняется DNS-идентичность; добавлены проверки на настоящем sing-box без изменения рабочего туннеля.
- Во вкладке VPN появился свёрнутый блок «Как пойдёт трафик сайта?». Он объясняет сохранённые правила, исключения, поддомены и приоритет включённого DPI. Это расчёт ожидаемого маршрута, а не проверка фактического IP или доступности сайта.
- VPN различает запущенный процесс и успешную HTTPS-проверку. Добавлены фоновая проверка с ограничением частоты, срок актуальности результата и повторная проверка после сна.
- Остановка VPN может отменить его незавершённый запуск, не останавливая DPI.
- Убрана повторная расшифровка неизменившегося списка серверов при обновлении интерфейса. Кэш содержит только разрешённые публичные поля, без ссылок подключения и токенов.
- Добавлен собственный Windows ProcessHost: принадлежащие приложению сетевые ядра завершаются вместе с владельцем. При штатной остановке приложение ожидает завершения самого ядра.
- Исправлены ложноположительные результаты замера скорости и HTTP-проверок DPI. Проверка HTTP не означает подтверждённую работу видео или голоса.
- Обновлена платформа Electron до 44.9.3; добавлены чистая сборка, проверка хэшей компонентов и дополнительные регрессионные тесты.

## Скачать и обновить

Windows 10/11 x64. Скачайте `Local-Route-Setup-0.29.0-x64.exe`, полностью выйдите из старой версии через меню значка в трее и запустите установщик. Не удаляйте старое приложение с очисткой данных для обычного обновления.

VPN требует вашего сервера или подписки. Telegram-прокси требует подтверждения подключения в Telegram Desktop. Работа зависит от сети и сервера.

## Известные ограничения

Локально прошли 163 теста и отдельная проверка запуска Electron: sandbox/contextIsolation, шифрование тестовых данных, отсутствие ошибок renderer и завершение собственного дочернего процесса. Это не заменяет испытания во всех сетях и на всех версиях Windows.

Это бета-версия. Установщик не подписан цифровым сертификатом. Приложение пока запрашивает права администратора. Kill switch не реализован: при отключении VPN трафик может идти напрямую. Полная матрица реальных TUN/IPv6/DoH и аварийного восстановления ещё не пройдена. Собственный DNS браузера и уже открытые соединения могут влиять на исключения.

Секреты, ссылки подписок и сырые журналы не публикуйте. Исходники и полный статус стабилизации доступны в репозитории.
