# Local Route

Локальное Windows-приложение для управления DPI-обходом YouTube/Discord и VLESS-маршрутизацией. Приложение работает на компьютере пользователя, не передаёт диагностику на сервер и не требует учётной записи.

> Проект предназначен для личного использования и тестирования в сетях, где это разрешено правилами провайдера и законом.

## Возможности

- автоподбор из нескольких локальных стратегий и сохранение первой подтверждённой;
- отдельная проверка каждой стратегии с результатом для выбранных сервисов;
- понятный журнал работы локального движка;
- запуск и аварийная остановка из приложения или системного трея;
- пользовательские домены в профиле;
- VLESS для выбранных сайтов, приложений Windows или всего внешнего трафика;
- ссылки на новости в [Telegram](https://t.me/TheLocalRoute) и [MAX](https://max.ru/channel_LocalRoute);
- весь трафик и результаты диагностики остаются на устройстве.

## Установка и запуск

1. Откройте страницу [Releases](../../releases) и скачайте последнюю Windows-сборку.
2. Распакуйте архив в постоянную папку без кириллицы в пути, например `C:\LocalRoute`.
3. Запустите `Run Local Route as Administrator.vbs`.
4. На вкладке «Проверка стратегий» подтвердите Zapret, добавьте VLESS при необходимости и используйте «Запустить всё».

Права администратора нужны только для локального сетевого драйвера WinDivert. Они не дают приложению доступ к удалённому серверу и не включают VPN.

## Telegram Desktop (TGWs)

На вкладке «Telegram Desktop» сохраните порт (по умолчанию 1443), запустите
локальный прокси и нажмите «Подключить Telegram». Подключение нужно подтвердить
в самом Telegram Desktop. Telegram Web и другие устройства этим локальным
подключением не обслуживаются. Секрет сохраняется через шифрование Windows.
Локальная готовность порта не подтверждает доступность Telegram у провайдера.
TGWs выходит напрямую, включая режим VLESS для всего интернета.

Ядро собрано из Flowseal/tg-ws-proxy, закреплённый commit указан в
THIRD_PARTY_NOTICES.md. Консольная точка входа: scripts/tg-entry.py.

## Разработка из исходников

Требуется Node.js 20+ и pnpm.

```powershell
pnpm install
pnpm test
pnpm start
```

Исходники разделены так, чтобы независимая от Windows логика профиля могла позднее использоваться в Android-клиенте. Управление локальным процессом и драйвером остаётся в `src/main.js`.
