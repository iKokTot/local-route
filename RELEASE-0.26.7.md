# Local Route 0.26.7 — локальная проверочная сборка

Прямые соединения используют отдельный DNS-over-HTTPS канал с числовым адресом и явным выходом direct. Системный DNS Windows больше не используется внутри TUN для разрешения прямых соединений: он мог возвращать запросы в сам туннель.

Сохранены исправления 0.26.6: DNS-привязки исключённых доменов, их локальный кэш и отступы блока проверки скорости.

Перед установкой завершите Local Route через меню трея. После обновления полностью перезапустите браузер и проверьте Авито при включённом VPN и отмеченном исключении. Настройки не удаляются.

Работа Авито в реальном браузере пока не подтверждена. Это кандидат для пользовательской проверки, не публичный релиз.
