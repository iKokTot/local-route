# Local Route 0.25.1 — исключения из VPN

- Вместо списка сайтов для VPN — весь внешний трафик через сервер, выбранные сайты и приложения напрямую.
- Принцип адаптирован из Android VpnExclusions: явные исключения, отдельный черновик, сохранение. Android использует пакеты приложений; Windows использует домены и имена процессов .exe.
- Популярные сайты: Авито, Wildberries, Ozon, ВКонтакте, Яндекс, Госуслуги и банки. Ничего не исключено автоматически; список доменов стартовый и не гарантирует полное покрытие ресурсов сервиса.
- Ручное добавление/удаление доменов, поддомены, библиотека приложений и выбор .exe.
- Прямые домены используют локальный DNS; остальные домены — DNS через VPN. Локальная сеть, TGWs и DPI-маршруты сохраняют приоритет.
- Старые allowlist-профили не инвертируются. Новый режим применяется только после сохранения пользователем; интерфейс показывает предупреждение.
- VPN-проверка исключений не выполняется: успешный ответ сервера не выдаётся за проверку прямого подключения.
- Поле выбора старых режимов убрано из Windows-интерфейса. Старый формат читается для безопасного перехода.

Применение: остановить VPN → настроить исключения → сохранить → запустить VPN.
Уже открытым соединениям может потребоваться перезапуск приложения/браузера.
Наличие правил не является доказательством доступности конкретного сервиса в сети пользователя.

Публикация на GitHub и в каналах отложена до проверки новой сборки.
