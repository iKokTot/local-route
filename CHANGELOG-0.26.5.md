# Local Route 0.26.5 — новый логотип

- Утверждён единый знак: разделённый поток DPI, два узла proxy и двойной путь VLESS сходятся в общий узел.
- Обновлены логотип интерфейса, значки окна и трея, EXE и установщика.
- Подготовлена многоразмерная Windows ICO.

Сетевые компоненты и логика работы не изменялись относительно 0.26.4. Версия остаётся beta.
Для VPN нужны собственный сервер или подписка; бесплатные серверы не предоставляются.

Обновление: полностью выйдите из приложения через трей и запустите новый установщик. Настройки не удаляйте.
