### Исключения из VPN

На вкладке «VPN» весь внешний трафик по умолчанию направляется через сервер.
Отмеченные сайты и приложения подключаются напрямую; VPN не скрывает их IP.
Можно выбрать популярные сервисы, добавить собственный домен (включая поддомены)
или имя .exe. В новых профилях рекомендуемые исключения включены по умолчанию.
Уже сохранённый выбор, включая пустой список, не перезаписывается. Чтобы отправить весь интернет
через VPN, отключите рекомендуемые исключения и оставьте список пустым. Локальная сеть, TGWs и домены включённого DPI
остаются напрямую независимо от пользовательского списка.

Для изменения остановите VPN, настройте список, нажмите «Сохранить исключения»
и запустите VPN снова. При обновлении старый выбор «через VPN» не инвертируется:
прежний профиль действует до явного сохранения нового режима. Появится подсказка.
Проверка сервера не подтверждает доступность исключённых сайтов или приложений.

### Автозапуск и совместный запуск

В общих настройках отдельно выбираются запуск приложения при входе в Windows,
компоненты для автозапуска (DPI / Telegram / VPN) и состав кнопки «Запустить всё».
Можно запускать только приложение в трей, сняв все галочки компонентов автозапуска.
Изменения сохраняются сразу и не включают/выключают работающие компоненты.
DPI запускает сохранённую стратегию; без неё пропускается. VPN без профиля также пропускается.
Устаревший переключатель совместного запуска убран из Telegram-вкладки.

Диагностика, сервисы DPI и исключения VPN свёрнуты и раскрываются по нажатию.

Локальное Windows-приложение для управления DPI-обходом YouTube/Discord и VLESS-маршрутизацией. Приложение работает на компьютере пользователя, не передаёт диагностику на сервер и не требует учётной записи.

> Проект предназначен для личного использования и тестирования в сетях, где это разрешено правилами провайдера и законом.

## Возможности

- автоподбор из нескольких локальных стратегий и сохранение первой подтверждённой;
- отдельная проверка каждой стратегии с результатом для выбранных сервисов;
- понятный журнал работы локального движка;
- запуск и аварийная остановка из приложения или системного трея;
- пользовательские домены в профиле;
- VLESS/Hysteria2 для всего внешнего трафика с исключениями сайтов и приложений Windows;
- ссылки на новости в [Telegram](https://t.me/TheLocalRoute) и [MAX](https://max.ru/channel_LocalRoute);
- диагностика хранится на устройстве; трафик VPN проходит через выбранный сервер.

## Установка и запуск

1. Откройте страницу [Releases](../../releases) и скачайте последнюю Windows-сборку.
2. Распакуйте архив в постоянную папку без кириллицы в пути, например `C:\LocalRoute`.
3. Запустите `Run Local Route as Administrator.vbs`.
4. На вкладке «Проверка стратегий» подтвердите Zapret, добавьте VLESS при необходимости и используйте «Запустить всё».

Права администратора нужны только для локального сетевого драйвера WinDivert. Они не дают приложению доступ к удалённому серверу и не включают VPN.

## Подписки и серверы во вкладке VLESS

Добавьте HTTPS-ссылку провайдера, список VLESS/Hysteria2 ссылок, Base64-список
или JSON с outbounds sing-box. Кнопка вставки читает буфер только по нажатию.
Ссылки подписок и ключи серверов хранятся через шифрование Windows и не входят
в публичный снимок состояния интерфейса. Импортированные правила маршрутизации,
локальные пути сертификатов и входящие порты не применяются.

Выберите сервер и нажмите «Подключить». Если соединение уже работает, выбор
другого сервера применяется после отключения и повторного подключения.
«Проверить серверы» выполняет HTTPS-запрос через временный локальный HTTP-прокси
для каждого подключения, без изменения системных маршрутов. «Автовыбор» выбирает
успешный сервер с минимальным временем этого запроса; это не ICMP ping.
Проверки идут по две одновременно, доступны прогресс и отмена.

Трафик и срок действия показываются из заголовка Subscription-Userinfo провайдера.
Обновление подписки выполняется кнопкой «Обновить». XHTTP и Xray JSON текущим
sing-box не импортируются как рабочие подключения; неподдерживаемые записи видны
в списке с пояснением. Приложение не выдаёт доступ к серверам без своей подписки.

## Telegram Desktop (TGWs)

На вкладке «Telegram Desktop» сохраните порт (по умолчанию 1443), запустите
локальный прокси и нажмите «Подключить Telegram». Подключение нужно подтвердить
в самом Telegram Desktop. Telegram Web и другие устройства этим локальным
подключением не обслуживаются. Секрет сохраняется через шифрование Windows.
Локальная готовность порта не подтверждает доступность Telegram у провайдера.
TGWs выходит напрямую, включая режим VLESS для всего интернета.

Ядро собрано из Flowseal/tg-ws-proxy, закреплённый commit указан в
THIRD_PARTY_NOTICES.md. Консольная точка входа: scripts/tg-entry.py.

## Разработка из исходников

Требуется Node.js 20+ и pnpm.

```powershell
pnpm install
pnpm test
pnpm start
```

Исходники разделены так, чтобы независимая от Windows логика профиля могла позднее использоваться в Android-клиенте. Управление локальным процессом и драйвером остаётся в `src/main.js`.
