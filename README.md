# Local Route

Локальное Windows-приложение для управления профилями DPI-обхода для YouTube и Discord. Приложение работает на компьютере пользователя: не является VPN, не передаёт диагностику на сервер и не требует учётной записи.

> Проект предназначен для личного использования и тестирования в сетях, где это разрешено правилами провайдера и законом.

## Возможности

- автоподбор из нескольких локальных стратегий и сохранение первой подтверждённой;
- отдельная проверка каждой стратегии с результатом для выбранных сервисов;
- понятный журнал работы локального движка;
- запуск и аварийная остановка из приложения или системного трея;
- пользовательские домены в профиле;
- весь трафик и результаты диагностики остаются на устройстве.

## Установка и запуск

1. Откройте страницу [Releases](../../releases) и скачайте последнюю Windows-сборку.
2. Распакуйте архив в постоянную папку без кириллицы в пути, например `C:\LocalRoute`.
3. Запустите `Run Local Route as Administrator.vbs`.
4. Выберите нужные сервисы и нажмите **Автоподбор и запуск**.

Права администратора нужны только для локального сетевого драйвера WinDivert. Они не дают приложению доступ к удалённому серверу и не включают VPN.

## Разработка

Требуется Node.js 20+ и pnpm.

```powershell
pnpm install
pnpm test
pnpm start
```

Исходники разделены так, чтобы независимая от Windows логика профиля могла позднее использоваться в Android-клиенте. Управление локальным процессом и драйвером остаётся в `src/main.js`.
