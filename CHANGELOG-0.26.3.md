# Local Route 0.26.3 — кандидат для проверки установки

- Постоянное предупреждение при аварийном отключении VPN: трафик может идти напрямую. Прежний успешный результат проверки сбрасывается.
- После выхода из сна прежняя проверка сервера больше не считается актуальной; предлагается проверить подключение. Автоматическая доступность сервера не гарантируется.
- Автозапуск сверяет путь к EXE и аргументы задания. При сохранённом включённом автозапуске новая версия пытается обновить устаревший путь. Если прав недостаточно, показывает предупреждение. Отключённое пользователем предпочтение не включается автоматически; повторное включение также перерегистрирует задание.
- EXE получает версию приложения и запрос административных прав, необходимых TUN/WinDivert. Цифровая подпись не добавлена: сертификата издателя нет.
- Добавлена сборка NSIS-установщика с выбором каталога, ярлыками и удалением. Пользовательские настройки сохраняются при удалении. Установщик не запускает приложение автоматически; при первом ручном запуске будет UAC.
- Kill switch не включён. При падении VPN приложение предупреждает о возможном прямом подключении, но не блокирует интернет. Это не fail-closed VPN.

Проверки интерфейса и управления компонентами выполняются автоматически. Реальные сценарии перезагрузки, сна, смены Wi-Fi/проводной сети, DNS/IPv6 и установки/удаления на чистой Windows остаются обязательными перед объявлением стабильного релиза. Установщик не опубликован автоматически.
