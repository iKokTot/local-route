# Объединение Local Route 0.25.0

## Источники

Community Windows 0.24.1 из предоставленного ZIP и наши локальные доработки 0.16.0. Исполняемые файлы из чужого архива не запускались; взяты исходники интерфейса и проверенные изменения управления компонентами. Используются наши существующие ядра.

## Что принято из Community

- Единый адаптивный интерфейс: обзор, DPI, Telegram, VPN, настройки.
- Сохранение черновиков при обновлениях состояния и явное применение изменений.
- Отмена длительных операций, последовательное управление процессами.
- Атомарное сохранение настроек с резервной копией.
- Разделение запуска процесса и подтверждения соединения, безопасная диагностика.
- Приоритет прямых DPI-маршрутов при совместной работе с VPN.

## Что сохранено из нашей версии

- Подписки, VLESS и Hysteria2, Base64 и ограниченный импорт sing-box JSON.
- Отображение неподдерживаемых транспортов без ложного обещания поддержки XHTTP.
- Метаданные трафика и срока подписки, имена групп.
- HTTPS-проверка серверов через отдельный локальный прокси без переключения системного TUN.
- Автовыбор по результатам проверки, не более двух параллельных проверок, общий лимит времени и отмена.
- Зашифрованное хранение ссылок и миграция библиотеки предыдущей локальной версии.

## Ограничения и риски

- Проверки интерфейса выполняются с имитацией состояния, это не доказательство обхода в конкретной сети.
- Доступность реальных подписок, Telegram и совместную работу драйверов нужно проверить на пользовательской сети.
- HTTP 403/404 не считается подтверждением работоспособности сервиса.
- Загрузка подписок принимает только HTTPS, не следует перенаправлениям и ограничена 512 КБ. Крупные списки можно импортировать текстом до 2 МБ.
- Hysteria2 зависит от доступности UDP; XHTTP этой сборкой ядра не поддерживается.
- Это Windows-сборка. Android не собирался и не проверялся.

## Восстановление

Предыдущие исходники сохранены в work/merge-backup-0.16.0, прежняя сборка остаётся в outputs/Local Route 0.16.0. Исходный ZIP друга не изменён. Новая сборка создаётся отдельно; публикация не выполняется автоматически.
